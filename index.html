AstroType

AstroType is a typing game I worked on that helps beginners practice HTML, CSS, and JavaScript syntax. Players type code snippets to destroy falling asteroids before they reach the bottom of the screen.

I worked on the gameplay logic, scoring system, and user interactions using JavaScript, HTML, and CSS.

NBA Workload & Performance Analysis

For this project, I analyzed 26,651 NBA player-game records to see how playing time and rest between games might affect player performance.

I used data analysis, statistical testing, and regression to explore relationships between workload, shooting efficiency, and player availability.
